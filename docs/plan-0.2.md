# Octet 0.2: แผน UX/UI และ Motion

อ่านโจทย์เป็น: เครื่องมือ Windows สำหรับคนทำ network ที่ต้องเร็วและนิ่ง ใช้ภาษาของ Octet เดิม (Fluent-ish, dark/light, accent เดียว) motion เป็นจุดขาย แต่ต้องมีเหตุผลทุกตัว

## หลัก motion (ใช้กับทุกหน้า)

1. **ขยับเฉพาะสิ่งที่เปลี่ยน** ไม่มี fade ทั้งหน้า ไม่มีกระพริบ ไม่มี blur
2. **มีทั้งเข้าและออกเสมอ** ขาออกเร็วกว่าขาเข้า (ราว 0.6 เท่า)
3. **ทิศทางบอกความหมาย** ไปทางขวา = ไปหน้าถัดไป, ลง = หายไป/พับ, ขึ้น = โผล่มา
4. **ตัดกลางทางได้** กดรัวๆ ต้องยกเลิกตัวเก่าแล้วไปสถานะสุดท้ายทันที ห้ามพึ่ง `animationend` ในการตั้งค่าสถานะจริง
5. **ตัวเลขหมุน ไม่กระโดด** ใช้ `countTo` / `countMac` ที่มีอยู่กับทุกตัวเลขที่เปลี่ยน (ms, จำนวน, IP)
6. **ข้อความยาวไม่เท่ากันใช้ `retext`** กล่องยืดหดให้ของข้างๆ เลื่อนตาม
7. **Reduced motion** (`calm`): ทุกอย่างเปลี่ยนทันที เหลือแค่ fade 0 ms
8. ใช้ token เดิมเท่านั้น: `--t-fast 140` `--t-base 180` `--t-slow 240` `--ease-out` `--ease-back` ไม่เพิ่ม library

## โครงสร้าง

```
┌ Rail ┬───────────────────────────────────────────┐
│      │ Wi-Fi (Office-5G)   ● Connected       ··· │
│      │ Qualcomm ...                  ▥ 02:00:..  │
│      │ [ IP & DNS | Advanced | Probe | Scan | Info ]
│      │                                           │
│      │   เนื้อหาของ tab (สูงคงที่ ไม่ resize)       │
│      │                                           │
│      ├───────────────────────────────────────────┤
│      │ ⚡ 802.11be · 6 GHz      [Revert] [Apply] │
└──────┴───────────────────────────────────────────┘
```

- หน้าต่างสูงจาก 510 เป็น 550 (+40 สำหรับแถบ tab) ความกว้างเท่าเดิม
- เปิดแอปมาอยู่ที่ IP & DNS เสมอ หน้าอื่นสร้าง DOM ตอนกดเข้าครั้งแรก (ไม่เสียเวลาเปิดแอป)
- สลับ adapter แล้วยังอยู่ tab เดิม
- คีย์บอร์ด: `Ctrl+1..5` เลือก tab, ลูกศรซ้ายขวาเมื่อ focus อยู่ที่แถบ tab
- Revert/Apply อยู่เฉพาะ IP & DNS กับ Advanced (ใช้ draft เดียวกัน) หน้าอื่นเหลือแค่บรรทัดสถานะ

## Motion: แถบ tab และการสลับหน้า

| จังหวะ | อะไรขยับ | ค่า |
|---|---|---|
| กด tab | แถบสีพื้นหลัง (pill) เลื่อนไปใต้ tab ใหม่ กว้างตามคำ | transform + width, 240 ms `--ease-out` |
| หน้าเก่าออก | fade + เลื่อน 10px ไปทางตรงข้ามกับทิศที่ไป | 140 ms |
| หน้าใหม่เข้า | fade + เลื่อนจาก 16px ทางทิศที่ไป มาที่ 0, เริ่มทับหน้าเก่า 60 ms | 240 ms `--ease-out` |
| Revert/Apply (ไปหน้าที่ไม่มีปุ่ม) | ปุ่มเลื่อนลง 8px + fade ออก, บรรทัดสถานะขยายเต็ม | 140 ms |
| Revert/Apply (กลับมา) | ย้อนกลับ, ปุ่มขึ้นจาก 8px | 240 ms |
| มีค่าแก้ค้างแล้วออกจาก IP & DNS | จุด badge เล็กที่ tab IP & DNS โผล่ (`pop` ที่มีอยู่) บอกว่ายังไม่ได้ Apply | 180 ms `--ease-back` |

## หน้า Advanced (หลาย IP, gateway, metric)

แทนหน้า Advanced TCP/IP ของ Windows: รายการ IP + subnet, รายการ gateway + metric, interface metric (Auto หรือกำหนดเอง)

- ใช้ draft เดียวกับ IP & DNS: IP แรกในรายการคือ IP ใน IP & DNS เป็นตัวเดียวกัน
- คำเตือน "Apply removes ..." เดิมหายไป เพราะผู้ใช้จัดการรายการเองได้แล้ว
- ใช้ได้เฉพาะ Manual (Windows บังคับเหมือนกัน) ตอน Automatic แสดงรายการแบบอ่านอย่างเดียวพร้อมปุ่ม "Switch to Manual"

| จังหวะ | Motion |
|---|---|
| เพิ่มแถว | แถวใหม่สูงจาก 0 + fade + ขึ้นจาก 4px (180 ms), แถวข้างล่างเลื่อนลงด้วย FLIP, focus ไปที่ octet แรก |
| ลบแถว | keyframe `leave` ที่มีอยู่ (ขวา 8px + fade + พับ) 140 ms, แถวข้างล่างเลื่อนขึ้น |
| ตั้งเป็น IP หลัก | สองแถวสลับที่กันด้วย FLIP 240 ms, IP ใน IP & DNS เปลี่ยนด้วย `countTo` |
| ค่าไม่ถูก | `shake` ที่มีอยู่บนช่องนั้นเท่านั้น |
| Automatic ↔ Manual | แถวเปลี่ยนจากอ่านอย่างเดียวเป็นแก้ได้: ขอบช่อง fade เข้า ไม่ขยับตำแหน่ง |

## หน้า Probe (ping พร้อมกราฟ)

```
[ 10.0.0.1                    ✕ ] [Ping ▾] [▶ Run]
 Gateway   DNS 1   DNS 2   + Add
 ● 10.0.0.1          2 ms    TTL 64
 ● 8.8.8.8          14 ms    TTL 117
┌ 10.0.0.1 ─────────────────────── Min  Avg  Max  Loss
│  ╱╲__╱‾╲___/\___ •               1    3    9    0%
└───────────────────────────────────────────────────
```

- ปุ่มลัด Gateway / DNS 1 / DNS 2 ดึงจาก adapter ปัจจุบัน
- ping ทุก 1 วินาที เก็บ 60 จุดล่าสุด วาดด้วย SVG `<polyline>` (60 จุด ไม่ต้องใช้ canvas หรือ library)
- ไม่พึ่งสีอย่างเดียว: ping ที่หลุดเป็นช่องว่างในเส้น + ขีดเล็กที่ขอบล่าง, และมีตัวเลข Loss เสมอ
- หยุดเองเมื่อออกจาก tab เกิน 1 นาที หรือปิดหน้าต่าง (ไม่ ping ทิ้งไว้เบื้องหลัง)

| จังหวะ | Motion | เหตุผล |
|---|---|---|
| Run → Stop | ไอคอน morph play เป็น stop (morphicons ที่มีอยู่), ปุ่มสลับสี 180 ms | บอกว่ากำลังทำงาน |
| กราฟเดิน | เส้นเลื่อนไปทางซ้ายต่อเนื่องหนึ่งช่องต่อวินาที แบบ linear | เวลาเดินเท่ากัน linear จึงถูกต้องตรงนี้ |
| จุดล่าสุด | จุดปลายเส้นกระเพื่อมหนึ่งครั้งต่อ sample (scale 1 → 1.6 + fade) | บอกว่ายังมีชีวิต |
| แกน Y เปลี่ยนสเกล | เส้นทั้งเส้นยืด/หดไปสเกลใหม่ 240 ms ไม่กระโดด | รักษาความต่อเนื่อง |
| Min/Avg/Max/Loss | `countTo` เฉพาะตัวที่เปลี่ยน | ตัวเลขไม่กระโดด |
| ms ในแต่ละแถว | `countTo` + สีเปลี่ยนตามเกณฑ์ (ปกติ / ช้า / หลุด) | |
| เพิ่ม/ลบเป้าหมาย | เหมือนแถวใน Advanced | ภาษาเดียวกันทั้งแอป |
| เลือกแถวเพื่อดูกราฟ | กราฟเก่า fade ออก 140 ms, กราฟใหม่วาดเส้นจากซ้ายไปขวา (stroke-dashoffset) 240 ms | |
| Stop | เส้นค้างไว้, จุดปลายหยุดกระเพื่อม, ป้าย "Paused" เข้าด้วย `retext` | |
| Reduced motion | กราฟวาดใหม่ทุก sample โดยไม่เลื่อน, ไม่มีจุดกระเพื่อม | |

## หน้า Scan (หา IP ว่าง)

- ช่วงเริ่มต้นคือ subnet ปัจจุบัน (เช่น 10.0.0.0/23) จำกัดไม่เกิน /22 (1022 ที่อยู่) ใหญ่กว่านั้นให้กรอกช่วงเอง
- วิธี: ARP ทุกที่อยู่แบบขนาน (ใช้ `SendARP` ที่มีอยู่) /24 ใช้เวลาราว 1-3 วินาที
- แสดงที่อยู่ว่างเป็นช่องตาราง, ที่อยู่ที่มีเจ้าของซ่อนไว้ใต้ "Show used (n)" พร้อมยี่ห้อจาก MAC
- บอกตรงๆ ใต้หัวข้อ: "ว่าง = ไม่มีใครตอบตอนสแกน เครื่องที่ปิดอยู่ก็ดูเหมือนว่าง"

| จังหวะ | Motion |
|---|---|
| กด Scan | แถบ progress ใต้ช่องช่วง scaleX ตามจำนวนที่เช็กแล้ว, ตัวนับ `countTo` "121 / 254" |
| เจอที่อยู่ว่าง | ช่องใหม่โผล่ด้วย `tile-in` ที่มีอยู่ (scale 0.8 + fade) ตามลำดับที่เจอ, ช่องที่มีอยู่ขยับด้วย FLIP ให้เรียงตามเลขเสมอ |
| สแกนจบ | แถบ progress fade ออก, หัวข้อเปลี่ยนเป็น "Available (n)" ด้วย `retext` |
| **กดช่อง IP ว่าง (motion หลักของ 0.2)** | ช่องนั้นลอยไปที่ช่อง IP address ใน IP & DNS: tab สลับ, IP เป็น Manual (segmented เลื่อน), กล่อง IP ที่ลอยไปหดลงในช่องพอดีแล้วหายไป (320 ms), octet ที่ต่างหมุนด้วย `countTo` |
| Copy | ไอคอน copy → check morph, ข้อความ "Copied" ด้วย `retext` แล้วกลับเองใน 1.6 วินาที |

## หน้า Info (Diagnostic Summary)

- ข้อความ monospace พร้อม Copy: adapter, สถานะ, MAC + ยี่ห้อ, link, IP/subnet/gateway (+ยี่ห้อ), DNS, ผล Probe ล่าสุดถ้ามี, เวลาสร้าง, เวอร์ชัน Octet
- ไม่มีข้อมูลส่วนตัวเกินที่หน้าจอแสดงอยู่แล้ว

| จังหวะ | Motion |
|---|---|
| สลับ adapter | เฉพาะบรรทัดที่เปลี่ยนใช้ `retext`, บรรทัดที่เหมือนเดิมนิ่ง |
| Copy | เหมือน Copy ในหน้า Scan |

## ลำดับการทำ (ทุกขั้นลองใน Web Demo ก่อน)

1. แถบ tab + motion สลับหน้า + ปุ่ม Revert/Apply เข้าออก + หน้าต่าง 550

2. ชื่อ tab: "Scan" หรือ "Find IP"
3. Probe มีแค่ Ping ก่อน หรือเผื่อ DNS lookup / Traceroute ใน dropdown ตั้งแต่แรก
