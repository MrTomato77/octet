## ข้อสรุปที่ใช้ทำงานต่อได้

- เป็นซอร์ส AutoIt จำนวน 44 ไฟล์ รวม 854,670 ไบต์: `.au3` 30, JSON ภาษา 9, Markdown 2, `.ico` 1, LICENSE 1 และ `.gitignore` 1 ไม่พบ `.exe` ในต้นไม้ที่ตรวจ
- ตัวซอร์สระบุเวอร์ชัน `2.9.8-b1` และวันที่ `5/15/2023` ใน `main.au3:112`–`113` ข้อมูลนี้เป็นค่าที่เขียนไว้ในไฟล์ ไม่ใช่การยืนยันว่าเป็นรุ่นล่าสุดหรือว่าตรงกับโปรแกรมที่เคยใช้งาน
- หน้าหลักมีสองคอลัมน์: โปรไฟล์ซ้าย อะแดปเตอร์/ค่าปัจจุบัน/ช่องตั้งค่า/โน้ตขวา งานหลักทำในหน้าเดียว ส่วน Settings/About/Blacklist เป็นหน้าต่างรอง
- Save บันทึกค่าจากฟอร์มลงโปรไฟล์ ส่วน Apply นำค่าจากฟอร์มไปใช้จริง เป็นการกระทำคนละอย่าง เลือกโปรไฟล์ครั้งเดียวเป็นการโหลดค่า; ดับเบิลคลิกและ Enter มีเส้นทางไป Apply
- IP และ DNS มีตัวเลือกโหมดแยกกัน โดย UI รองรับ DHCP IP + manual DNS แต่เมื่อเลือก static IP จะบังคับ manual DNS การตั้งค่าใช้ `netsh` ส่วน Release/Renew ใช้ `ipconfig` ผ่านคิวคำสั่งแบบไม่บล็อกหน้าจอ
- คิวมี timeout ค่าเริ่มต้น 10 วินาที แต่การแปลผลใช้ข้อความ เช่น `failed`/`exists` และไม่ได้ตรวจ exit code พร้อมเทียบผลจริงกับค่าที่ต้องการ จึงไม่ใช่เครื่องวินิจฉัย DHCP อย่างครบถ้วน
- โปรไฟล์และ Options อยู่ร่วมใน INI; Export คัดลอกทั้งไฟล์ Open เปลี่ยนไฟล์ที่ใช้งาน ส่วน Import ผสานโปรไฟล์เข้าไฟล์ปัจจุบัน

รายละเอียดและหลักฐานแต่ละข้ออยู่ในเอกสารย่อย ไม่ควรใช้สรุปนี้แทนเงื่อนไขทั้งหมดของแต่ละคำสั่ง

## วิธีอ่านระดับความแน่นอน

- **พบในซอร์ส**: มีคำสั่ง เงื่อนไข หรือเส้นทางเรียกที่อ่านได้โดยตรง
- **ข้ออนุมาน/ความเสี่ยง**: ผลที่คาดจากโค้ด แต่ยังไม่ได้ทำซ้ำกับโปรแกรมจริง
- **ยังไม่ยืนยัน**: ต้อง build/run หรือมีหลักฐานเพิ่ม
- **ข้อเสนอ v2**: แนวทางสำหรับงานใหม่ ไม่ใช่ความสามารถที่ยืนยันว่าของเดิมมี

ใช้แนวทางจาก skill `reverse-engineer-anything`: เมื่อมีซอร์สให้วิเคราะห์ซอร์สโดยตรง ไม่เรียก REA engine ไม่ถอดไบนารี และไม่รันคำสั่งตั้งค่าเครือข่าย การอ้างอิง `ไฟล์:บรรทัด` ทั้งหมดเริ่มจากโฟลเดอร์ `source` ด้านบน ส่วนรหัส `SRC-*` เป็นรหัสหลักฐานภายในเอกสาร ไม่ใช่ Evidence ID ที่ออกโดย REA

## ขอบเขตและการเก็บรักษา

ตรวจเส้นทาง startup, UI actions, profiles/INI/CLI, adapter discovery, IP/DNS/DHCP, async callback, tray/settings/language และ update/debug ในระดับซอร์ส ไม่ได้ตรวจทุกคำสั่งภายใน third-party libraries ไม่ได้ compile หรือเปิด GUI ไม่ตรวจ/เปลี่ยนค่าของอะแดปเตอร์จริง และไม่อ้างว่าได้ทดสอบผล DHCP บนเครื่องนี้

มีรายการ hash ของไฟล์ต้นฉบับสำหรับเทียบก่อนและหลังการจดบันทึก ไม่มีการ commit หรือแก้ไฟล์ใน `source/` รายละเอียดผลตรวจอยู่ในทะเบียนหลักฐาน
