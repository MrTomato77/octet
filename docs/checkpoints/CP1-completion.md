# Remaining UX improvements, implementation checkpoint

Date: 2026-10-17
Scope: the seven reviewed improvements. Network data remains fixtures. No Windows network mutation, administrator helper, Apply/Renew/Release, or DHCP probes were added.

1. Semantic differences: subnet masks and prefixes normalize through the core parser. IP/DNS mode differences have their own diamonds. Numeric markers are hidden for inactive inputs. Invalid values use warnings rather than diamonds after validation.
2. Validation: outstanding errors are recomputed after edits, so changing a memo does not clear an IP error. Click a detail to scroll and focus its editor. Details wrap; core validation strings have Thai translations. Field warnings retain hover reasons.
3. Restore saved: sidebar action is enabled only for dirty drafts. A confirmation explains that only the selected draft is discarded. Other profile drafts and adapter data are unchanged.
4. Preview: per-field Setting/Before/After table with adapter name and ID. DHCP future lease values are not guessed. IP mode, static address/prefix/gateway, DNS mode and manual servers are compared individually.
5. Profile mode icons: derive from the current draft rather than the saved config. Dirty state remains independent.
6. Persistence: %LOCALAPPDATA%/SimpleIPv2/state.json stores committed profiles, unsaved drafts, selection, language, dark/light preference and window size. JSON schema version 1. Flush about once per second and on normal exit; Save explicitly commits a draft. UTF-8 content. Temporary-file write plus flush, previous-file backup, then replacement. If primary is missing, a valid backup is read. Corrupt/future data is preserved and writes blocked; explicit Recover backup preserves corrupt primary separately. Reject invalid saved configs, unsupported prefix/server counts and duplicate identities. Detect outside changes before overwriting loaded state. This is not a crash-proof transactional database; forced termination can lose edits since the last flush. Store uses local machine user data, not the executable directory.
7. Language and input: Thai validation and field names, localized preview values and status switching. --thai / --english override stored language. Noto remains embedded. Tab skips mouse-copy reference labels and moves between editors. Plain Enter does not apply settings.

## Segmented IPv4 / CIDR input refinement

IPv4, gateway and DNS controls now use four octet editors separated by fixed dots inside one border. All rows reserve identical octet positions and the right-side marker area. The subnet adds a linked /prefix editor; valid prefixes render the matching mask, while editing mask octets updates the derived prefix. Incomplete drafts remain strings and survive existing persistence/profile switching. Whole IPv4 paste into any segment replaces the full field. Subnet accepts /prefix paste. Dot moves to the next segment, valid three-digit octets advance automatically, Tab follows octets then prefix, and Backspace from an empty segment moves back. Invalid pasted full fields remain available to normal validation rather than being silently truncated. Out-of-range values are not clamped.

Verification: 27 tests passed (9 core, 18 app); clippy all targets/features passed. Added segmented draft, IPv4 paste/dot-navigation and subnet CIDR-paste tests. Updated focus traversal and painted-text alignment checks for the segmented control. Inspected Thai/English, light/dark and invalid native framebuffer captures.
