# Simple IP v2

## Register

product

## Users

Windows users moving between home, office and laboratory network configurations. The current owner values Simple IP Config's compact single-page workflow. Names and notes must support Thai and English.

## Product Purpose

View the selected adapter, prepare IPv4 and DNS settings in one form and apply changes with evidence of the resulting Windows state. Current implementation checkpoint is a simulated CP1 prototype, without a Windows network backend.

## Brand Personality

Direct, practical, composed. Operational clarity comes before decoration.

## Anti-references

Avoid a multi-page settings wizard, ornamental dashboard metrics, nested decorative cards, and copying the original program's icons or visual assets. Preserve the useful workflow, rather than its implementation.

## Design Principles

1. Keep current settings and desired settings together on one page.
2. Show the change preview before anything is applied.
3. Label simulated data and unverified outcomes explicitly.
4. Never silently discard edits; switching adapters keeps an edited form.
5. Use native keyboard expectations and show the target before an action.

## Accessibility & Inclusion

The accepted plan requires Thai text entry, keyboard navigation and high-DPI testing. Use readable body contrast, visible focus and text beside status colors. Do not claim screen-reader conformance or hardware IME coverage until tested. Avoid decorative animation.


Current refinement: profiles removed; single adapter form, language/theme/window-size preferences, per-field change previews, issue focus, and localized validation. Network adapter data remains fixtures; no Apply/Renew/Release backend.
